# Avelis

Avelis adalah studio menggambar offline untuk Android. Pengembangan Avelis oleh **kyn-x**.

Kode berasal dari [KriTap](https://github.com/horihori2013/KriTap), fork dari [Krita](https://krita.org/). Engine Krita, kredit kontributor, hak cipta, dan pemberitahuan lisensi upstream disertakan. Lihat [COPYING](COPYING), [LICENSES](LICENSES/) dan [AUTHORS](AUTHORS).

## APK Android

Setelah perubahan di-commit ke `main`, buka **Actions → Avelis Android APK**. Jika build berhasil, unduh artefak sesuai ABI perangkat. Workflow juga bisa dipicu manual. Build memakai paket native Java dan C++/Qt dari toolchain Android/KDE. Target awal Android 7+ dengan ABI yang sesuai. Instalasi lintas perangkat belum diverifikasi.
